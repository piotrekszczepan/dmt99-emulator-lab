# Third-party components

The application installs Pillow, NumPy, Unicorn Engine and Capstone under their respective licenses.

The setup script clones the public reverse-engineering project
[`smhgzll/dmt-99-multimeter-custom-firmware`](https://github.com/smhgzll/dmt-99-multimeter-custom-firmware)
as a runtime dependency. Its source and firmware images are not copied into this repository.
At the time this package was prepared, that upstream repository did not contain a top-level
license file. Check its current terms before redistributing any part of it.

FNIRSI and DMT-99 are product names of their respective owner. This is an independent,
unofficial research and testing tool.
