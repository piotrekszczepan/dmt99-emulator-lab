# Sterowanie menu DMT-99

| Przycisk miernika | Działanie w menu | Wejście MCU |
|---|---|---|
| HOLD / REL | poprzednia pozycja | PC10 / zdarzenie 1 |
| mA / A | następna pozycja | PC11 / zdarzenie 2 |
| VΩHz | wejdź w zaznaczoną pozycję | PC9 / zdarzenie 3 |
| NCV / LIVE | wróć o poziom | PC12 / zdarzenie 4 |
| AUTO / MENU krótko | zatwierdź wybór | PC8 / zdarzenie 5 |
| AUTO / MENU długo | otwórz menu albo wyjdź | PC8 / zdarzenie 6 |
| Zasilanie | wyłącz miernik | PC2 / zdarzenie 8 |

W aplikacji lewy przycisk myszy na AUTO/MENU oznacza krótkie naciśnięcie, a prawy — długie.
